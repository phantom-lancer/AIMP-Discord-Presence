## Presence layout

* line 1 - track title
* line 2 - artist
* line 3 - album, **skipped** when it is identical to the title (Discord would print the same
  text twice)
* hover over the big cover - the album as well, Discord reuses one field for both
* hover over the small AIMP logo - the album

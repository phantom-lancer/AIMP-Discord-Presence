# Contributing

Приветствуются issues и pull request'ы.

## Что полезно знать

- Плагин — .NET Framework 4.8, собирается под **x86** (AIMP 32-битный):
  `dotnet build AIMP-Discord-Presence-2 -c Release -p:Platform=x86`.
- Настроек в GUI нет, всё в `config.xml`. Любой новый провайдер обложек обязан иметь
  значения по умолчанию и переживать пустой/битый `config.xml`.
- Точка входа модуля — `aimp_DiscordPresence2.dll`, это копия `aimp_dotnet.dll`. Не удаляйте
  её и не заменяйте на пустышку: без неё AIMP молча игнорирует плагин.
- Архивы для установки собираются `publish_plugin_zip.ps1`. `Compress-Archive` пишет в zip
  разделитель `\`, что не соответствует спецификации zip, и AIMP отвергает такой пакет с
  «invalid file format».
- Провайдер обложек возвращает **https-ссылку**. Локальные пути, `file://` и base64 Discord
  не показывает — это ограничение самого клиента, а не плагина.

## Проверка перед PR

- Сборка без ошибок и предупреждений.
- Новый провайдер покрыт комментарием в `docs/Compare.md` и отдельным файлом в `docs/`.
- Логи пишутся в `%AppData%\BowieD_AIMPDiscordPresence2\`, а не в `Console`.

## Стиль

Табы, `private` поля с подчёркиванием, braces на новой строке, C# 7.3 — это уровень языка
проекта.
